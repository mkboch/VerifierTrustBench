The question the software exists to answer: when should an AI verifier's conclusion count as scientific verification, rather than merely a correct-looking verdict?

The measurement, in short

Asking a model "is there anything wrong with this manuscript?" and asking it "is relation R broken — yes or no?" are not the same test, and the gap between them is usually reported as if it were one quantity. It is at least two. How much the system was told and the shape of the answer it had to give move together unless you separate them deliberately.

So the protocol walks up a ladder of four rungs. Each step changes exactly one thing:

  1. Blind finding listNothing is pointed at.
  2. Category-targeted finding listThe family of defect is named. The location is not.
  3. Relation-targeted finding listThe exact relation is named, in words. Same answer format as above.
  4. Relation-localized binary verdictThe same exact relation. Only the response interface changes.

The last two rungs carry identical information. Any difference between them is the response format, not the knowledge.

Why every rung is run twice

A system scored only on manuscripts that really are broken is rewarded for suspicion. Flag everything and you look perceptive. So each rung is run in two evidence states on the same relation:

  • E0The manuscript with the tested relation deliberately broken. A detection counts here.
  • E1The manuscript exactly as published, where that same relation is sound. A flag here is a false alarm.

Charging each rung for what it flags on the sound relation is what fair scoring means. A finding about some other part of the manuscript counts neither way, so the false-alarm rate is specific to the relation under test.

What gets computed

sensitivity        = E0 hits / n
false-alarm rate   = E1 false alarms / n        (tested relation only)
specificity        = 1 − false-alarm rate
balanced accuracy  = (sensitivity + specificity) / 2
d′                 = z(hit rate) − z(false-alarm rate)

d′ uses the Hautus (1995) log-linear correction — add a half to each count and one to each total — applied to every cell rather than only to the extreme ones, so the estimator is the same function everywhere.

Two rungs are compared on the complete-case paired set: the cells where both rungs answered scoreably in both states. Intervals come from a manuscript-cluster bootstrap, because relations inside one manuscript are not independent — the whole estimand is recomputed inside each replicate.

Two weightings, and they can disagree. Pooling lets a system with more eligible cells count for more; equal-system weighting averages per-system differences first. Neither is the answer, and a contrast reported without naming its weighting is not interpretable. The tool below always shows you both.
